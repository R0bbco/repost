Политика конфиденциальности Repost

Repost — программа для личного использования, которая работает только на компьютере владельца.

Какие данные используются

  • При подключении YouTube программа получает от Google токен доступа к каналу пользователя (права на загрузку видео и чтение названия канала).
  • Токен и настройки хранятся только локально на компьютере пользователя. Они не передаются разработчику и третьим лицам.
  • Программа не собирает персональные данные, не ведёт аналитику и не показывает рекламу.

Как используются данные Google

Данные, полученные через API YouTube, используются только для загрузки видео, которые пользователь сам выбрал, на его собственный канал. Использование соответствует Google API Services User Data Policy, включая требования Limited Use. Также действуют Условия использования YouTube и Политика конфиденциальности Google.

Как отозвать доступ

Удалите программу и её папку данных или отзовите доступ на странице myaccount.google.com/permissions.

Privacy Policy (English)

Repost is a personal desktop application that runs only on the user's computer. When the user connects YouTube, the app receives an OAuth token used solely to upload videos chosen by the user to the user's own channel and to read the channel name. Tokens and settings are stored locally and are never sent to the developer or any third party. The app collects no personal data, analytics or advertising data. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
