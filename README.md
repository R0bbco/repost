# Репостер: как пользоваться

Программа ищет видео на YouTube, в TikTok, ВКонтакте, Reddit и Instagram, принимает ссылки
на ролики и файлы с компьютера, показывает
их списком, а отмеченные заливает на твою страницу или в группы ВК и на YouTube-каналы.

## 1. Установка (один раз)

1. **Поставь Python.** Открой python.org → Downloads → скачай установщик для Windows.
   В первом окне установщика **обязательно поставь галочку «Add python.exe to PATH»**,
   потом «Install Now».
2. **Сложи файлы программы в одну папку**, например `C:\Repost`:
   `repost_app.py`, `start.bat`, `requirements.txt`, `README.md`.
   Лучше не на Рабочем столе и не в OneDrive.
3. **Дважды щёлкни `start.bat`.** В первый раз он сам скачает всё нужное — это
   5–10 минут, окно будет чёрным с текстом, так и должно быть. Потом откроется программа.

Дальше программа запускается так же: двойной щелчок по `start.bat`. Чёрное окно
мелькнёт и закроется — это нормально, программа откроется отдельно.

**Нужен VPN.** TikTok, YouTube и Instagram из России нормально работают только через VPN.
Включи VPN на компьютере до запуска. ВК работает и с VPN, и без.

## 2. Работа в три шага

Вкладка **«Поиск и заливка»**:

1. **Слева** отметь, где искать, впиши слова или `#хэштег`, нажми **«Найти»**.
2. **В центре** появится список. **Двойной щелчок по строке — видео играет прямо в
   программе**, под списком, без скачивания на диск. Кнопка «Отметить для заливки»
   ставит галочку у того, что сейчас смотришь. Можно и просто ставить галочки в списке.
3. **Справа** отметь, куда залить, и нажми **«Залить отмеченные»**.

Внизу окна — журнал: что происходит и какие были ошибки. В колонке «Статус» видно,
что уже залито. Одно и то же видео на одну площадку дважды не зальётся.

Чтобы справа появились площадки, сначала подключи аккаунты (разделы 3 и 4).

## 3. Подключение ВКонтакте

Ключи и «приложения разработчика» не нужны: программа работает с ВК через обычный
сайт в своём окне браузера.

1. Вкладка «Аккаунты и настройки» → **«Войти во ВК»**. Откроется окно браузера с VK Видео.
   Войди в аккаунт как обычно и **закрой окно** — вход запомнится.
2. В поле ниже впиши ссылки на свои группы, куда хочешь заливать, по одной в строке,
   например `https://vk.com/club123456`. Нажми «Сохранить настройки».
3. Справа на первой вкладке появятся «ВК — моя страница» и твои группы.

Как идёт заливка: для каждого видео открывается окно браузера, программа сама нажимает
«Добавить видео», подставляет файл, вписывает название и описание и жмёт
«Опубликовать». **Не трогай это окно, пока оно работает.** Если программа не нашла
какую-то кнопку, она напишет в журнале, что нажать руками, и подождёт.

Для первых заливок включи галочку **«Я сам проверяю видео и нажимаю „Опубликовать“»**:
программа всё заполнит, а ты посмотришь, что получилось, нажмёшь кнопку и закроешь
окно. Когда убедишься, что всё попадает куда надо, галочку можно снять.

Проверь на первом видео, что оно появилось именно в группе, а не на личной странице.

## Папки и место на диске

Насовсем программа ничего не хранит. Ролик скачивается во **временную папку**, заливается
на все отмеченные площадки и сразу удаляется — в каждый момент на диске лежит только
один ролик. Если программа закрылась посреди заливки, остатки удалятся при следующем
запуске.

На вкладке «Аккаунты и настройки» → «Папки» можно выбрать:
- **Временную папку** — например, на другом диске или флешке, чтобы не занимать
  системный. Рядом видно, сколько там свободно.
- **Папку «Скачать»** — для площадки «Папка на компьютере». Только она хранит видео
  насовсем: удобно, если хочешь залить куда-то руками.

Просмотр в программе идёт потоком, без скачивания. Если площадка не отдаёт поток
(так бывает с TikTok), программа скачивает маленькую копию во временную папку и удаляет
её, как только переключишься на другое видео.

## 4. Подключение YouTube

Google тоже требует «ключ приложения». Создаётся один раз, бесплатно.

1. Открой **console.cloud.google.com**, войди в Google-аккаунт.
2. Вверху нажми на выбор проекта → **«New Project»** → название любое → Create.
3. Меню слева → **APIs & Services → Library** → найди **YouTube Data API v3** → **Enable**.
4. Меню → **APIs & Services → OAuth consent screen** (может называться Google Auth
   Platform) → **Get started**: название любое, свой e-mail, тип **External** → сохранить.
5. Там же, раздел **Audience**: нажми **«Publish app»** (иначе вход будет слетать
   каждые 7 дней).
6. Раздел **Clients** (или Credentials) → **Create client / Create credentials →
   OAuth client ID** → тип **Desktop app** → Create → **Download JSON**.
7. В программе: «Аккаунты и настройки» → **«Подключить канал YouTube»** → выбери скачанный файл.
   Откроется браузер: войди в Google, выбери канал. На экране «Google hasn't verified
   this app» нажми **Advanced → Go to … (unsafe)** — это твоё же приложение. Разреши доступ.

Чтобы подключить второй канал, нажми кнопку ещё раз и войди под другим аккаунтом.

Ограничения YouTube:
- примерно 6 заливок в сутки на один ключ;
- пока Google не проверил твой проект, залитые ролики могут принудительно стать
  **закрытыми** (private). Проверка запрашивается в той же консоли (YouTube API audit).

## 5. TikTok, Reddit, Instagram и добавление без поиска

**TikTok и Reddit** — только поиск, ключей не нужно. TikTok по хэштегам обычно ищет без
входа; для поиска по словам нажми «Войти в TikTok», войди и закрой окно. Reddit входа не
требует. При поиске в TikTok открывается окно браузера и само листает страницу — не
закрывай его; если появилась капча — пройди её.

### Что писать в строку поиска

В поле можно написать **несколько запросов, по одному в строке** — программа найдёт по
каждому и сложит в один список.

- **Слова** (`пранки над друзьями`). Пока стоит галочка «Слова должны быть в названии или
  описании ролика», остаются только ролики, где эти слова реально есть в тексте. Окончания
  не важны: «рыбалка» найдёт и «рыбалку».
- **#хэштег** (`#котыприколы`) — ролики с этим хэштегом.
- **@автор** (`@имя_канала`) — свежие ролики одного автора (YouTube, Shorts, TikTok, Instagram).
- Источник **YouTube Shorts** ищет только короткие вертикальные ролики, **YouTube** — все.

### Как находить именно то, что нужно

Широкие запросы вроде «смешные видео» дают всё подряд. Лучше работает так:

1. **Пиши узко.** Не «смешные видео», а сам сюжет: «пранки над друзьями», «коты роняют
   вещи», «неудачи на работе», «реакция детей». Несколько таких строк = одна тема.
2. **Минус-слова** убирают лишнее: `мультик, игра, minecraft, roblox`.
3. **Фильтры:**
   - «Просмотров от» — например 50 000, чтобы отсечь ролики, которые никто не смотрел;
   - «Когда вышло» — за неделю или месяц, чтобы были свежие;
   - «Язык текста» — «русский», если нужны русскоязычные ролики (смотрит на название
     и описание; у роликов без текста язык не определить, такие отсеются);
   - «Без подборок, нарезок, озвучек» — убирает компиляции и перезаливы; список слов
     можно дописать на вкладке «Аккаунты и настройки»;
   - «Скрывать то, что уже заливал»;
   - «Порядок» — по просмотрам или сначала новые.
4. **Сохрани тему.** Когда подобрал удачные запросы и фильтры — нажми **«Сохранить тему»**
   и назови её («Пранки», «Животные»). Потом выбираешь тему в списке — форма заполняется,
   жмёшь «Найти».
5. **«Найти похожие».** Нашёл ролик точно в тему — выдели его (или открой в плеере) и
   нажми «Найти похожие» справа от плеера. Программа поищет по его хэштегам и автору и
   допишет найденное в конец списка.
6. **«Новые у моих авторов».** На вкладке «Аккаунты и настройки» → «Мои авторы» впиши
   ссылки на авторов, которые снимают то, что тебе нужно (по одной в строке). Кнопка слева
   покажет только их ролики, которых ты ещё не видел. Это самый точный способ: хорошие
   авторы снимают одно и то же стабильно.

Что учесть: TikTok показывает ролики той страны, где включён VPN. Для русских роликов
ищи русскими словами и ставь «Язык текста: русский». У Shorts с хэштег-страниц и
страниц авторов YouTube не отдаёт дату и просмотры — фильтры по ним такие ролики не режут.

### Поиск в Instagram

1. «Аккаунты и настройки» → **«Войти в Instagram»**. Откроется окно браузера: войди как
   обычно и закрой окно. Без входа Instagram поиск не показывает вообще.
2. На первой вкладке отметь слева **Instagram** и ищи как обычно: слова, `#хэштег` или
   `@автор`. Откроется окно, программа сама листает страницу — не закрывай его.

Важно знать:
- Instagram не любит, когда страницы листает программа. Не запускай поиск десятки раз
  подряд: он может попросить подтвердить вход или временно ограничить аккаунт.
- Если окно входа не даёт войти или поиск ничего не находит — Instagram не пускает
  программу. Обходить это программа не будет; пользуйся ссылками и файлами (ниже).
- **Поиска по X (Twitter) нет**: площадка не пускает программы без платного доступа.

### Как добавить видео без поиска (Instagram и откуда угодно)

Слева под кнопкой «Найти» есть два способа добавить ролики без поиска. Они встают в
тот же список, сразу с галочкой — дальше как обычно: посмотреть, выбрать площадку, залить.

**1. «Вставить ссылки…»** — для открытых роликов.
- В Instagram: под роликом нажми «Поделиться» (самолётик) → **«Копировать ссылку»**.
- Удобно собирать ссылки с телефона: пересылай их себе в «Избранное» Telegram, потом
  на компьютере скопируй все разом и вставь в окно — по одной в строке.
- Работают ссылки и с TikTok, YouTube, ВК, Reddit и многих других сайтов.
- Если в журнале написано «сайт отдаёт это видео только после входа» — Instagram не
  отдал ролик программе. Тогда используй способ 2.

**2. «Добавить файлы с компьютера…»** — самый надёжный.
- **Ролики партнёров:** попроси прислать исходный файл (Telegram «как файл», облако).
  Это лучшее качество и точно без водяного знака.
- **Свои ролики из Instagram:** в приложении открой свой Reels → «⋯» → «Скачать».
- **Чужие открытые ролики:** в приложении Instagram «Поделиться» → «Скачать» (если автор
  разрешил скачивание). Instagram добавит на такой ролик имя автора.
- Перекинь файлы на компьютер и выбери их кнопкой. Сами файлы программа не удаляет.

Галочка **«Новый поиск не очищает список»** позволяет собрать в один список ролики из
нескольких поисков, ссылок и файлов.

## 6. Обновления

Программа умеет обновляться сама — больше не нужно скачивать архив и заменять файлы.

**Вариант 1 — автоматически через GitHub (настроить один раз):**
1. Зарегистрируйся на **github.com** (бесплатно).
2. Нажми «+» вверху справа → **New repository** → название `repost` → **Public** →
   Create repository. Секретов там не будет: токены и входы хранятся только у тебя
   на компьютере.
3. Подключи GitHub к Claude: на claude.ai → Настройки → раздел с подключениями →
   GitHub. Тогда Claude сможет выкладывать обновления прямо в этот репозиторий.
4. В программе: «Аккаунты и настройки» → «Обновления» → впиши `твой_логин/repost` →
   «Сохранить настройки».

Дальше при каждом запуске программа проверяет, есть ли новая версия, и спрашивает,
установить ли её. Можно проверить вручную кнопкой «Проверить сейчас».

**Вариант 2 — архивом из чата:** скачай `Repost.zip` и нажми «Установить из архива…».
Распаковывать и заменять файлы не нужно.

В обоих вариантах программа сначала проверяет, что новый файл исправен, а старые
версии сохраняет в папку `backup` (в папке данных). Если в обновлении появились новые
компоненты, при перезапуске на минуту откроется чёрное окно установки — это нормально.

## 7. Правила, чтобы каналы не заблокировали

1. Заливай свои ролики и те, на которые автор дал разрешение. По жалобе автора
   ролик удалят, а канал или группа получит предупреждение или блокировку.
2. Не снимай галочку «Указывать автора и ссылку на оригинал» для чужих роликов.
3. Не заливай десятки роликов подряд: 5–10 за раз, пауза между заливками от 20 секунд.
4. На YouTube правила строже, чем во ВК: за чужой контент отключают монетизацию.

## 8. Если не работает

| Что видишь | Что делать |
|---|---|
| start.bat пишет «Python не найден» | Переустанови Python с галочкой «Add python.exe to PATH» |
| YouTube / TikTok: «не получилось» | Включи VPN; для поиска по словам в TikTok выполни вход |
| Instagram: «сначала войди» или пусто | «Аккаунты и настройки» → «Войти в Instagram», включи VPN; не помогло — ссылки и файлы (раздел 5) |
| Находит мало видео | Увеличь «Видео с источника»; ослабь фильтры (просмотры, период, язык); сними галочку «Слова должны быть в названии или описании». В журнале видно, сколько сайт показал и сколько отсеяно |
| Ссылка из Instagram не добавляется | Включи VPN; если пишет про вход — скачай ролик в приложении и добавь файлом (раздел 5) |
| TikTok: найдено 0 | Включи «Показывать окно браузера», пройди капчу; попробуй хэштег |
| ВК: «не нашёл кнопку…» | Сделай этот шаг руками в открытом окне, программа продолжит сама. Пришли разработчику файлы из папки `debug` в папке данных |
| ВК: окно открылось на странице входа | Нажми «Войти во ВК» на вкладке «Аккаунты и настройки» и войди заново |
| ВК: видео попало не туда | Проверь ссылку на группу; ты должен быть её админом или редактором |
| YouTube: дневной лимит | Продолжи завтра |
| Не скачалось | Закрой и открой программу (загрузчик обновляется сам), попробуй ещё раз |
| Видео в программе не играет | Нажми «Открыть в браузере»; для TikTok нужен VPN |
| Программа не открывается после обновления | Скопируй файлы из папки `backup` обратно в папку программы |

Все ошибки подробно пишутся в файл `app.log` в папке данных (её путь — первая строка
журнала в программе). Там же хранятся входы в аккаунты — эту папку никому не передавай.
