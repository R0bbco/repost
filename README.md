# Репостер: как пользоваться

Программа ищет видео на YouTube, в TikTok, ВКонтакте, Reddit и X (Twitter), показывает
их списком, а отмеченные заливает на твою страницу или в группы ВК и на YouTube-каналы.

## 1. Установка (один раз)

1. **Поставь Python.** Открой python.org → Downloads → скачай установщик для Windows.
   В первом окне установщика **обязательно поставь галочку «Add python.exe to PATH»**,
   потом «Install Now».
2. **Сложи файлы программы в одну папку**, например `C:\Repost`:
   `repost_app.py`, `start.bat`, `requirements.txt`, `README.md`.
   Лучше не на Рабочем столе и не в OneDrive.
3. **Дважды щёлкни `start.bat`.** В первый раз он сам скачает всё нужное — это
   5–10 минут, окно будет чёрным с текстом, так и должно быть. Потом откроется программа.

Дальше программа запускается так же: двойной щелчок по `start.bat`.

**Нужен VPN.** TikTok, X и YouTube из России нормально работают только через VPN.
Включи VPN на компьютере до запуска. ВК работает и с VPN, и без.

## 2. Работа в три шага

Вкладка **«Поиск и заливка»**:

1. **Слева** отметь, где искать, впиши слова или `#хэштег`, нажми **«Найти»**.
2. **В центре** появится список. Поставь галочки у нужных видео. Двойной щелчок по
   строке открывает видео в браузере, чтобы посмотреть.
3. **Справа** отметь, куда залить, и нажми **«Залить отмеченные»**.

Внизу окна — журнал: что происходит и какие были ошибки. В колонке «Статус» видно,
что уже залито. Одно и то же видео на одну площадку дважды не зальётся.

Чтобы справа появились площадки, сначала подключи аккаунты (разделы 3 и 4).

## 3. Подключение ВКонтакте

Ключи и «приложения разработчика» не нужны: программа работает с ВК через обычный
сайт в своём окне браузера.

1. Вкладка «Аккаунты» → **«Войти во ВК»**. Откроется окно браузера с VK Видео.
   Войди в аккаунт как обычно и **закрой окно** — вход запомнится.
2. В поле ниже впиши ссылки на свои группы, куда хочешь заливать, по одной в строке,
   например `https://vk.com/club123456`. Нажми «Сохранить настройки».
3. Справа на первой вкладке появятся «ВК — моя страница» и твои группы.

Как идёт заливка: для каждого видео открывается окно браузера, программа сама нажимает
«Добавить видео», подставляет файл, вписывает название и описание и жмёт
«Опубликовать». **Не трогай это окно, пока оно работает.** Если программа не нашла
какую-то кнопку, она напишет в журнале, что нажать руками, и подождёт.

Для первых заливок включи галочку **«Я сам проверяю видео и нажимаю „Опубликовать“»**:
программа всё заполнит, а ты посмотришь, что получилось, нажмёшь кнопку и закроешь
окно. Когда убедишься, что всё попадает куда надо, галочку можно снять.

Проверь на первом видео, что оно появилось именно в группе, а не на личной странице.

## Площадка «Папка на компьютере»

Просто скачивает отмеченные видео без водяного знака в папку (по умолчанию
`Видео\Repost`, меняется на вкладке «Аккаунты»). Пригодится, если хочешь залить
куда-то руками или если автоматическая заливка не сработала.

## 4. Подключение YouTube

Google тоже требует «ключ приложения». Создаётся один раз, бесплатно.

1. Открой **console.cloud.google.com**, войди в Google-аккаунт.
2. Вверху нажми на выбор проекта → **«New Project»** → название любое → Create.
3. Меню слева → **APIs & Services → Library** → найди **YouTube Data API v3** → **Enable**.
4. Меню → **APIs & Services → OAuth consent screen** (может называться Google Auth
   Platform) → **Get started**: название любое, свой e-mail, тип **External** → сохранить.
5. Там же, раздел **Audience**: нажми **«Publish app»** (иначе вход будет слетать
   каждые 7 дней).
6. Раздел **Clients** (или Credentials) → **Create client / Create credentials →
   OAuth client ID** → тип **Desktop app** → Create → **Download JSON**.
7. В программе: «Аккаунты» → **«Подключить канал YouTube»** → выбери скачанный файл.
   Откроется браузер: войди в Google, выбери канал. На экране «Google hasn't verified
   this app» нажми **Advanced → Go to … (unsafe)** — это твоё же приложение. Разреши доступ.

Чтобы подключить второй канал, нажми кнопку ещё раз и войди под другим аккаунтом.

Ограничения YouTube:
- примерно 6 заливок в сутки на один ключ;
- пока Google не проверил твой проект, залитые ролики могут принудительно стать
  **закрытыми** (private). Проверка запрашивается в той же консоли (YouTube API audit).

## 5. TikTok, X, Reddit

Они только для поиска, ключей не нужно.

- **TikTok**: по хэштегам обычно ищет без входа. Для поиска по словам нажми
  «Войти в TikTok», войди как обычно и закрой окно браузера.
- **X**: без входа не ищет. Нажми «Войти в X», войди, закрой окно.
- **Reddit**: вход не нужен.

Для входов заводи отдельные аккаунты, не личные: за автоматический поиск аккаунт
могут ограничить. При поиске в TikTok и X открывается окно браузера и само
прокручивает страницу — не закрывай его. Если появилась капча — пройди её.

## 6. Правила, чтобы каналы не заблокировали

1. Заливай свои ролики и те, на которые автор дал разрешение. По жалобе автора
   ролик удалят, а канал или группа получит предупреждение или блокировку.
2. Не снимай галочку «Указывать автора и ссылку на оригинал» для чужих роликов.
3. Не заливай десятки роликов подряд: 5–10 за раз, пауза между заливками от 20 секунд.
4. На YouTube правила строже, чем во ВК: за чужой контент отключают монетизацию.

## 7. Если не работает

| Что видишь | Что делать |
|---|---|
| start.bat пишет «Python не найден» | Переустанови Python с галочкой «Add python.exe to PATH» |
| YouTube / TikTok / X: «не получилось» | Включи VPN; для X и TikTok выполни вход |
| TikTok: найдено 0 | Включи «Показывать окно браузера», пройди капчу; попробуй хэштег |
| ВК: «не нашёл кнопку…» | Сделай этот шаг руками в открытом окне, программа продолжит сама. Пришли разработчику файлы из папки `debug` в папке данных |
| ВК: окно открылось на странице входа | Нажми «Войти во ВК» на вкладке «Аккаунты» и войди заново |
| ВК: видео попало не туда | Проверь ссылку на группу; ты должен быть её админом или редактором |
| YouTube: дневной лимит | Продолжи завтра |
| Не скачалось | Закрой и открой программу (загрузчик обновляется сам), попробуй ещё раз |

Все ошибки подробно пишутся в файл `app.log` в папке данных (её путь — первая строка
журнала в программе). Там же хранятся входы в аккаунты — эту папку никому не передавай.
